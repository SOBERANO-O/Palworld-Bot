# Palworld-Bot
PALWORLD BOT é uma ferramenta automatizada para Palworld capaz de coletar recompensas e reiniciar expedições automaticamente. O sistema utiliza reconhecimento da interface do jogo para otimizar farms e reduzir tarefas repetitivas, contando com uma interface moderna e simples de usar. E apenas a 1° versão então pode ter erros e bugs. Para o bot funcionar e necessario que o personagem esteja na frente do Escritório de Expedição de Pals no circulo azul da construçao se não ira funcionar. Atualmente ele nao funciona em outros idiomas por causa de como foi feito, ele tambem so tem as 4 primeiras opçoes de expediçoes.
